# Security Policy

## Educational Scope

This repository contains defensive cybersecurity learning material. Examples are intended for authorised laboratories and training environments only.

## Reporting a Problem

Do not publish credentials, personal data, sensitive logs, or exploitable secrets in a public issue. For ordinary content errors, open an issue with a clear description and suggested correction.

## Supported Content

Because this is an educational handbook rather than a production software product, no formal version support policy currently applies. Security-sensitive examples should still be reviewed and updated when tools or standards change.
